| **`QC-001`** | API Error Mapping | Low / Info | **OPEN** | **Mô tả**: Khi người dùng `sales` gọi API quản trị không có quyền (như `/api/retrieval/settings`), hàm `requireRole("admin")` ném ra `Error("FORBIDDEN")`.
